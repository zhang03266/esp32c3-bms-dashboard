# ESP32-C3 BMS 电池观测站

阿里云 IoT 设备 `esp32c3_zyc` 的只读网页看板。单节电芯、温度、Wi-Fi、蓝牙、告警保护、趋势、设备固件和 OTA 分模块展示。自动隐藏未上报、空值和空字符串属性；收到有效数据后自动显示，数值 0 和布尔 false 保留。

支持手机、平板和桌面自适应布局。手机端属性明细采用卡片排版；右上角太阳/月亮图标切换日夜主题并保存选择，首次打开时跟随系统主题。

网页默认每 10 秒查询，可选择 5、10、15、30、60、180 或 300 秒，设置保存在本机浏览器。后端缓存 8 秒，5 秒刷新可能读到相同的缓存数据；数据过期阈值会随刷新间隔调整。连接状态和属性新鲜度分别展示。图表只保留当前会话最近一小时、最多 360 条新记录，支持 CSV 导出；刷新页面会清空。CSV 每行对应一次新上报时的已知属性快照，第二列为本次更新中最新属性的北京时间；各属性可能有不同的上报时间，未报告的值为空。

## 访问

通过 GitHub Pages 打开页面。普通网址不读取设备数据；访问设备数值需要管理员私下提供的完整 `#token=` 链接。个人链接包含只读查看权限，切勿提交到仓库。

## 数据接口

页面通过 HTTPS 调用阿里云函数计算，只读取服务器配置的固定设备与字段。应用使用 `Authorization: Bearer` 校验随机查看令牌；运行时通过只读 RAM 角色临时凭证查询 IoT。浏览器不使用 DeviceSecret 或云账号 AccessKey。

仓库仅发布静态网页源码，不包含运行时令牌、部署凭据、云配置、真实数据快照或个人二维码。后端部署源代码及配置由管理员在本地单独保管。网页采用外部 CSS/JavaScript 版本参数，便于发布更新后刷新加载。

传感器需要持续供电、联网。静态页面无需电脑保持开机；阿里云函数计算及公网流量可能按量计费。

状态码显示设备原值；未经设备协议确认，不将保护/均衡/OTA 状态码解释为安全结论。电芯以电池轮廓显示，最高电压标红、最低电压标蓝。
